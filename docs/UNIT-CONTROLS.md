- 부대·편제·저장 스키마, 체력·행동력·보급·보급망·턴·AI 유지.
- 전투 결과표의 계수·주사위·반격·피해·사거리·지경선 제한 유지.
- 사단의 기존 `unit.sector.allocations`, `reserveShare`, HQ 위치 유지.
- 전략 HUD, 레이어, 미니맵, 카메라·줌 알고리즘 유지.

엔진 변경은 중복 규칙을 방지하기 위한 조회 경로 정리다.

`attackBlockReason`을 공격 가능 여부와 UI 사유가 공유한다.
기존 결과표를 `combatDamage`로 추출해 실행과 프리뷰가 함께 사용하며,
프리뷰는 주사위를 굴리거나 게임 데이터를 변경하지 않는다.

## 화면 및 상태 전이

기존 상시 338px 우측 패널 / 모바일 29dvh 하단 패널을 기본 레이아웃에서 접었다.
지휘·부대·시설·기록 버튼으로 기존 패널을 필요할 때만 연다.
부대 선택 시 얇은 상태 바와 현재 가능한 명령만 표시한다.
상태 바는 NATO 기호·부대명, 공격·기본 방어·현재/최대 전력·이동력·보급·탐지,
산악 지형 보너스를 아이콘과 숫자로 표시한다. 기존 모델에는 독립 탄약 수치가
없으므로 임의의 탄약 데이터를 만들지 않았다. 전력/보급의 최대값은 기존 100,
이동력 최대값은 기존 편제의 `game.spec(u).mp`를 쓴다.

| 상태 | 진입 | 지도 입력 / 복귀 |
|---|---|---|
| `select` | 초기·선택 해제 | 아군 탭 → `move` |
| `move` | 아군 선택·명령 취소 | 실제 도달 가능 타일 → 기존 이동 명령; 다른 아군 → 선택 교체 |
| `attack-preview` | 적 기호 또는 탐지된 적 책임 타일 탭 | 지도 이동 명령 차단; 공격 실행 / 취소 → `move` |
| `sector` | 독립 전투지경선 버튼 | 후보 타일 포함·제외; 확정 → `Game.setSector`; 취소 → 원본 보존; 둘 다 `move` 복귀 |
| `detail` | 펼치기·같은 부대 다시 탭·지휘 메뉴 | 지도를 드래그/확대할 수 있으나 이동 명령 차단; 닫기 → `move` 또는 `select` |
| `unload` | 실제 승선 부대가 있는 수송선단 | 기존 하선 명령만 입력; 완료/취소 → `move` |

한 개의 `mode`가 지도 입력을 분기한다. 공격/지경선/하선 중에는 턴 종료와
다른 지휘 메뉴 전환도 차단한다. Escape와 Android 뒤로 가기는 현재 편집·상세를
먼저 닫는다. 대기는 행동력을 보존하고 선택을 해제한다.

선택은 절제된 황색 링, 이동은 반투명 청록 헥스, 공격은 붉은 테두리와 ⌖로 구분한다.
아군 지경선은 평시에도 황색 외곽선으로 표시하고 선택 시 강화한다.
편집 후보는 점선, 기존 배분은 바깥 실선, 편집값은 안쪽 선과 ✓로 구분한다.
원본 배분은 확정 전까지 손대지 않는다. 변경 없이 확정하면 기존 비율도 유지한다.
타일 포함·제외 시에는 기존 정책인 전선 80% 균등·예비 20%를 적용하며
모두 제거하면 기존 HQ·예비 100% 상태가 된다.

## 모바일 면적

412×915에서 기존 모바일 하단 패널은 265.35px, 맵은 약 445.65px였다.
새 맵은 711px로 전체 화면의 77.7%를 차지한다. 선택 상태 바는 80px,
상황형 버튼 포함 128px, 아래 메뉴 여백 포함 하단 조작 영역은 약 182px이다.
하단 조작 영역을 제외한 맵 높이는 약 529px로 기존보다 약 83px / 19% 넓다.
전략 HUD·기존 지도 위 보조 정보는 이 비교에서 그대로 유지한다.

360×800: 맵 596px, 상태 바 80px. 915×412: 맵 256px, 상태 바 48px.
새 명령·펼치기·취소/확정 버튼은 최소 44px 터치 영역이며 아이콘은 14–16px다.
긴 숫자 줄과 상황형 버튼은 필요한 경우 가로 스크롤하고 화면 전체가 넘치지 않는다.
상세는 최대 높이를 제한한 스크롤 패널이며, 닫으면 지도 면적을 되찾는다.

## 남은 제한

- 물리적 Android 기기의 멀티터치와 APK/lint는 로컬 JDK·SDK 부재로 실행하지 않았다.
  핀치 입력은 기존 포인터 핸들러 자동 테스트로 검증했으며 실제 브라우저에서는 드래그·줌을 확인했다.
- 기존 지경선의 연결성·HQ 거리 제한·재배치 비용은 원래 미구현이며 이번에도 추가하지 않았다.
- 저배율에서 밀집된 편제 기호/라벨은 겹칠 수 있다. 기존 줌, 부대 목록,
  상세의 같은 헥스 부대 선택 기능을 보존했다.
- 피해 범위는 기존 추상 전투 결과표 기준이다. 전투 이탈 임계치와 실제 병력 수를 혼동하지 않도록 전력으로 표기한다.
