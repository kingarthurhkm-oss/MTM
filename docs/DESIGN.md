# 구현 설계

## 결정론적 게임 엔진

`engine.js`는 UI와 Android에 의존하지 않습니다. Xorshift32 상태를 저장 파일에 포함해 같은 명령과 저장 상태는 같은 전투 주사위와 이벤트를 재현합니다. API는 명령 결과를 `{ok, message}`로 반환하며 지형·제대·행동력을 직접 검증합니다.

## 지도와 좌표

72열 × 126행 odd-r offset 헥스입니다. row/col은 입력과 타일 ID, axial은 모든 기하·인접·거리·클릭 판정에 사용합니다. 마스크와 CSV를 오프라인으로 컴파일한 metadata가 유일한 지도입니다. 경로는 Dijkstra 탐색이며 KTX railEdges는 이동과 보급 비용에 적용됩니다. [좌표와 원본 예외](HEX-GRID.md).

## 기반시설 연계

| 종류 | 게임 효과 |
|---|---|
| 전력 | 보급 효율, 예비 보급 생성 |
| 통신 | 다음 턴 지휘점 |
| 항만 | 공급 출발점, 함정 보급 효율, 지상부대 승선 |
| 철도 | 공급 출발점, 전체 공급 효율 |
| 도로 | 해당 도로 회랑의 이동 비용과 공급 경로 비용 |
| 공항 | 해당 비행단 공급·출격 가능 여부와 방어 출격 효율 |
| 에너지 | 이동 비용과 공급 효율 |

시설은 0–100 가동률을 연속 값으로 유지합니다. 등급 표시는 정상(75 이상), 부분(40 이상), 제한(20 이상), 기능 상실(20 미만)입니다. 승선은 항만 25 이상, 출격은 공항 25 이상이라는 별도 조건이 있습니다.

## 공급

통제 중인 가동 도시·항만·철도와 적재 물자가 있는 보급대에서 육상 공급 필드를 계산합니다. 적 통제 지역과 바다는 육상 보급 경로에서 제외하며 원본 목포역의 철도 연결 노드만 rail edge를 통해 접근합니다. 도로 손상, 산악, 연료·전력·철도 효율은 경로 비용을 증가시킵니다. 부대 보급은 턴마다 `공급 연결도 × 32 − 18`만큼 바뀝니다. 부족하면 전투력·이동력이 하락하고 추가 전력 손실이 발생합니다. 수송 물자는 유한 적재량입니다.

공급은 게임용 단순화입니다. 각 시설의 실제 처리량이나 국가 물류망은 반영하지 않으며, 각 통제 거점이 공급원으로 작동합니다. 공격 경로 최적화나 현실 보급량 환산을 제공하지 않습니다.

## 전투와 AI

공격력/방어력 비율을 여섯 열의 추상 전투 결과 표에 배정하고 1–6 주사위로 결과를 변동시킵니다. 공급, 잔여 전력, 산악, 방어 태세, 지상 지원과 플레이어 전투 태세를 반영합니다. 북한 AI는 인근 적 부대에 접근하고 가능한 전투를 수행하는 단순 규칙 기반 AI입니다. AI는 플레이어와 같은 지형·사거리·공급·행동력 제약을 적용받으며, 탐지 정보는 단순화되어 있습니다.

핵 위협은 위기 지수 85 이상의 추상 이벤트이며 시설·보호·결속 지수만 변경합니다. 표적, 무기 모델, 위력, 사상자, 폭발·낙진·방사선 모형은 없습니다.

## 저장과 Android

자동 저장은 `localStorage`, 기기 간 전송은 JSON입니다. 불러오기는 버전·배열 크기·고정 부대/시설 ID·좌표·범위·수송 관계를 먼저 검증하며, 실패 시 기존 상태를 보존합니다. 사용자 문자열은 UI에 넣기 전에 HTML escape 처리합니다.

Android는 API 26 이상을 대상으로 하고, 고정 `appassets.androidplatform.net/game/` 경로의 번들 파일만 제공합니다. 인터넷·위치·광범위 저장소 권한이 없습니다. 네이티브 인터페이스는 사용자가 선택한 파일에 JSON을 쓰고 읽는 두 동작으로 제한됩니다. 요청 파일은 2MB로 제한합니다.

## 남은 제품 확장 영역

멀티플레이, 대규모 캠페인 편집기, 오디오, 접근성용 지도 대체 이동 UI, 게임패드, Google Play 배포, 실제 기기 성능 계측은 이 버전의 범위에 포함되지 않습니다. 현실 군사·시설 데이터로 게임 수치를 대체하는 기능도 제공하지 않습니다.


## 지도 재생성

`npm run build:map` → `npm test` → `npm run standalone`. 저장 버전 3과 mapId를 함께 검증하며 이전 지도 저장은 재투영하지 않고 거부합니다. 시군 대표점은 region_id와 원본 도시·역 또는 대략적 행정지역 중심으로 다시 생성하고 빈 아군 육지로 분산합니다.
